# 🚀 Generative AI Cohort - Learning Journey (Aug-Sept 2025)

Welcome to the **Generative AI Cohort 2025**! 

Over the past **8 weeks**, a group of passionate learners joined us to dive deep into the world of **Prompt Engineering, Retrieval-Augmented Generation (RAG), LangChain, and LangGraph**.  

This README serves as a record of our journey – week by week highlights, key learnings, and hands-on projects. 🌟  

---

## 📅 Course Timeline

### ✅ Week 1: Introduction to Prompt Engineering  
- What is Prompt and Prompt Engineering?  
- Access to the Prompt Engineering course on **DeepLearning.AI**  
- Completed the course together 🎓  
- Fine-tuning prompts + live **doubts class**  
- Built our **first Chatbot** from the course material   

---

### ✅ Week 2: Prompt Engineering & Introduction to RAG  
- Explored **prompting techniques** and their practical use  
- Reviewed all participant-built Chatbots with techniques applied  
- Discussed **limitations of prompt engineering**  
- **Introduction to RAG**   

---

### ✅ Week 3: Introduction to RAG  
- Started with **RAG fundamentals**  
- Learned **chunking** and did hands-on practice  
- Introduction to **embeddings** + practical session  
- Introduction to **Vector Databases** 🗄️  

---

### ✅ Week 4: Diving Deeper into RAG  
- Walkthrough of **Vector Databases**  
- Practical implementation  
- Introduction to **LangChain**   
- Group **project discussion**  
- **Semantic Search deep dive** using LangChain  

---

### ✅ Week 5: Understanding the Response Generation Part  
- Consolidated **Semantic Search** concepts with practice  
- Introduction to **Reranking** (to refine results)  
- Hands-on reranking implementation  
- Weekend challenge: Build a **functioning RAG project using LangChain**   

---

### ✅ Week 6: Introduction to LangGraph  
- **LangChain vs LangGraph** – key differences  
- Core components of LangGraph: **Node, State, StateGraph, Edge**  
- Group discussion on design  
- Built a **small POC graph**  

---

### ✅ Week 7: Diving Deeper into LangGraph  
- Explored **Conditional Edges** and their applications  
- Designed workflows: **Conditional, Parallel, Sequential**  
- Built and tested all workflow types   

---

### ✅ Week 8: Memory & Checkpointers in LangGraph  
- Introduction to **Memory and Checkpointer** concepts  
- Hands-on practical for saving memory in graphs  
- Final assignment: **Build a LangGraph that saves memory with a checkpointer**   

---

## 🏆 Achievements
- Built **multiple Chatbots and RAG pipelines**  
- Learned to integrate **LangChain** and **LangGraph** for agentic workflows  
- Delivered a complete **end-to-end Generative AI learning experience**  
- Students completed **POCs, projects, and assignments** week by week
